# Map-entry block changes on dev

The audit covers polishedcrystal `56a2e5296` and atlas `d87d280`. Across all 612 map scripts, 188 callback registrations point to 185 distinct entry labels. Of the 55 tile callbacks, 41 use ordinary script-level block edits without assembly helpers or macro expansion. The atlas handled the tested branches on 40 of those maps. Violet Outskirts exposed a border-coordinate gap. A second visible gap is the player's bedroom, where an assembly special writes blocks without using the script command. ## The lighthouse

Olivine City tests `EVENT_JASMINE_RETURNED_TO_GYM`, then tests the game clock for `NITE`. Each failed check jumps to the same local return. The two writes affect adjacent 32-pixel blocks. The atlas reads script coordinates in 16-pixel units, so `(32,14)` and `(34,14)` land at block columns 16 and 17 on row 7. [Callback](https://github.com/Rangi42/polishedcrystal/blob/56a2e52966d988e43fc6bddc802a246dc5038663/maps/OlivineCity.asm#L61) · [Clock and block command handlers](https://github.com/Rangi42/polishedcrystal/blob/56a2e52966d988e43fc6bddc802a246dc5038663/engine/overworld/scripting.asm)

| Jasmine returned | Morning | Day | Evening | Night |
| --- | --- | --- | --- | --- |
| No | 98, 99 | 98, 99 | 98, 99 | 98, 99 |
| Yes | 98, 99 | 98, 99 | 98, 99 | 9A, 9B |

Values are hexadecimal block IDs. The renderer passed all eight combinations. The audited snapshot started with the event clear. [The subsequent game-source update](https://github.com/Rangi42/polishedcrystal/commit/06f86bffae6c2b42dee4101b7be2d4ac87727b9c) sets the event on dev, so the windows light up at Night. [A later callback change](https://github.com/Rangi42/polishedcrystal/commit/22008c5b58816c30a8f6bc54a1399bd13424f119) adds Evening as well. All four window block IDs use the same four collision values. ## Minimum implementation

1. **Keep the existing script evaluator for ordinary edits.** The direct callbacks here need a program counter, local labels, the last check result, event and engine flags, a clock slot, ordered block writes and a successful `endcallback`. Their conditions use `checkevent`, `checkflag` and the single `checktime 1 << NITE` expression. They branch with `iftruefwd`, `iffalsefwd` and `sjumpfwd`. Cianwood Gym also sets temporary flags. Other families add `checkscene`, `clearevent`, a backward conditional and whole-map replacement. A general RGBDS or Game Boy interpreter is unnecessary for these paths.
2. **Support connection-border writes separately from the map's own blocks.** Before HM05, Violet Outskirts writes `$0a` at `(4,-2)` and `(6,-2)`. The atlas accepts unsigned coordinates and silently abandons this branch. The game fills the connection border before it invokes the tile callback. These cells project onto block positions `(7,8)` and `(8,8)` of Route 42, both `$02` in Route 42's own map. A minimal fix would parse signed coordinates, split writes into interior and border collections, then apply the border collection when drawing the originating map's connection strip. A negative Python index would corrupt an interior row. A permanent rewrite of Route 42 would lose the distinction between the two viewpoints. The continuous overworld needs an explicit choice about which viewpoint to show at this seam. [Violet Outskirts callback](https://github.com/Rangi42/polishedcrystal/blob/56a2e52966d988e43fc6bddc802a246dc5038663/maps/VioletOutskirts.asm#L35) · [Map load order](https://github.com/Rangi42/polishedcrystal/blob/56a2e52966d988e43fc6bddc802a246dc5038663/home/map.asm#L503) · [North connection](https://github.com/Rangi42/polishedcrystal/blob/56a2e52966d988e43fc6bddc802a246dc5038663/data/maps/attributes.asm#L410)
3. **Model the bedroom special from the game's initial decoration state.** `InitDecorations` equips a feathery bed and Town Map poster. The renderer currently returns `$01` and `$6b` at script coordinates `(0,4)` and `(6,0)`. The game writes `$83` and `$6c` and sets the poster event. A small handler can read the initial decoration IDs and their block attributes and return those edits and the event update. Custom carpets, plants and saved-room layouts would require the selected decoration state. [Initialization and special](https://github.com/Rangi42/polishedcrystal/blob/56a2e52966d988e43fc6bddc802a246dc5038663/engine/overworld/decorations.asm#L1013) · [Decoration attributes](https://github.com/Rangi42/polishedcrystal/blob/56a2e52966d988e43fc6bddc802a246dc5038663/data/decorations/attributes.asm)
4. **Report unsupported execution paths.** Keep the current all-or-nothing behavior for a callback that fails partway. Have an audit or test report the map, source line and command when a reachable path falls back. A legitimate early return with zero changes and an unsupported write currently look identical. Test both sides of the HM05 branch, the parent and neighbor map buffers, and the bedroom's two default blocks and poster flag before changing the export.

## Entry points and limits

The scan started at the registered labels for 56 new-map, 55 tile, 52 object and 25 command-queue callbacks. It followed local and cross-label script branches, including shared targets in other map files, and inspected helper calls that can affect terrain. No other callback class directly executes a script block write on map entry in this pin. A command-queue callback can install code for later. For example, Cianwood Gym registers a stone table and returns. Pushing a boulder later runs a waterfall animation with several intermediate `changeblock` commands. The separate tile callback chooses its initial waterfall state. [Cianwood Gym](https://github.com/Rangi42/polishedcrystal/blob/56a2e52966d988e43fc6bddc802a246dc5038663/maps/CianwoodGym.asm#L43)

The table below lists all 55 tile callback registrations. The control-flow comparison for the 41 direct routines exercised 179 combinations of relevant flags and clocks, using the atlas's first-visit assumption for the two hidden grottos. One combination differed, the pre-HM05 Violet Outskirts case. All 2,048 combinations of the eleven underground door flags matched the expanded source door definitions. The existing map/palette and fixed-weather suites passed 29 tests, including both scene values for each bridge and both regional Pokémon Center layouts. This is a source and renderer audit of a pinned release. Emulator playthroughs, arbitrary save states, and every post-entry interaction remain outside its coverage.

| --- | ---: | --- |
| Direct script blocks | 41 | One signed border case. The two grottos use the first-visit Pokémon snapshot. |
| Assembly bridge helpers | 5 | Atlas recognizes `changebridgeblock` sequences. Both scene values evaluate. Published maps use the default scene. Route 47 also has a direct conditional door write. |
| Macro-generated doors | 1 | The eleven door definitions expand to conditional writes. |

| Bedroom decoration special | 1 | The game's default bed and poster writes are missing. |
| Rugged Road North scene setup | 1 | Updates the south map's bridge scene from the previous map and warp. Writes no local blocks. Travel-dependent bridge views would need that entry context. |
